                              HOW TO USE
================================================================================

1. Run the demo (no weights required):
   $ python hubconf.py

2. Import and use in code:
   
   # Create model without pretrained weights
   model = create('yolov7', pretrained=False, channels=3, classes=80, autoshape=True)
   
   # Or use the convenience function
   model = yolov7(pretrained=False)
   
   # Run inference
   import torch
   dummy_input = torch.randn(1, 3, 640, 640)
   with torch.no_grad():
       output = model(dummy_input)

3. With pretrained weights (after downloading):
   $ python download_and_test.py
   $ python hubconf.py
